# dsh-roaming

**0.4 框架首版，分步交付中；尚未安装到日常 profile，也未修改真实云仓库。**

## 分层

```text
独立云记忆仓库 ↔ Git 本地仓库 ↔ 编解码/三路比较 ↔ 自定义映射区
                                               ├─ 本机隐藏条目 → 原生 session 句柄
                                               └─ 外机条目 → 按机器分组的 DSH 工作区
```

仓库是用户的数据资产，不属于插件；其它消费者可以独立读取。[数据格式说明](./MEMORY_FORMAT.md) 定义机器身份/名称/配置、原生格式的对话数据和全局记忆。压缩/数据版本只属于仓库，不替 DSH 升级原生会话。

## 本次实现

- 独立 `portable-memory/1` 格式，JSON 索引和 SHA-256 定址的 zstd 对象；不依赖 DSH。
- 本地 Git 仓库和映射区独立可配置。上传先刷新选中的本机会话，再编码/Git 发布；下载先拉数据，再交给独立桥接。
- 三路比较：单边更新同步；相同内容不重复；双方更新不同则分裂保留两个对话，同一冲突不重复生成副本。
- 日常只保留一个「同步」按钮，后台一次完成刷新本机镜像、拉取、三路比较、回传和映射；配置、会话选择和日志收在折叠区，不暴露上传/下载步骤。
- 每次同步使用独立 runId，日志记录阶段、耗时、冲突数和失败位置，不记录会话正文或凭据。
- DSH 桥接首版：已选本机隐藏句柄、外机 v4 纯文本普通会话、追加更新、冲突分裂后的句柄重绑定。仅写映射会话，不改写本机原生会话。

## 配置

默认启动新框架；只有显式设置 `mode: preview` 才进入历史只读预览，不自动迁移旧状态。

```yaml
mode: framework
repoUrl: https://github.com/CuriousStreas/Mem_DSH.git
repoDir: D:/Memory/repository
mappingDir: D:/Memory/mapped
sessionBridge: false
```

- `repoUrl` 是可替换的数据源，不绑定上面示例仓库；也支持本地 Git 地址。
- `repoDir` 与 `mappingDir` 必须互不包含。机器身份保存于独立框架配置，不依靠显示名称。
- `sessionBridge: false` 仅同步数据，不访问 DSH 会话。显式打开后才可列出并选择本机会话、创建外机会话。
- 启动和保存配置不发起同步；只有点击「同步」才执行。
- 旧 `hosts/` 格式通过同一个按钮兼容读取，保留原始会话及配置/记忆文件；尚不回传，也不伪装为已验证的原生 v4 映射。界面明确显示部分完成/只读结果，不把它冒充完整双向同步，不覆盖旧仓库。
- 本机可用 `<DSH_HOME>/roaming/location.json` 的 `{ "rootDir": "自选绝对路径" }` 指定数据根目录，设置、默认仓库、默认映射和日志均置于其中；优先级低于插件 `config.rootDir`。通用默认路径不变，不把个人路径写入开源代码。

## 当前未完成

1. 外机续聊传回本机原生 session 的写回仍关闭；下载数据会保留并报告待处理，不能用旧原生内容再次覆盖它。
2. 原生附件、fork、未知 DSH 格式暂不桥接。全局记忆可作为独立数据同步，但未自动读取/覆盖 Mnemon 运行态；机器配置也不自动应用。
3. 日常 GUI 尚未安装验证。UI/API 接线已写入代码，不代表现有页面已经更新。

DSH 当前官方 API 能创建普通会话并注册机器工作区，但日志实体仍存于 DSH 默认持久层；自定义映射区保存工作区、数据和绑定，**不是独立的原生日志存储根**。这里不改 DSH 底层、不换全局 provider、不用软链接伪装隔离。

## 最小验证

只运行一个功能冒烟，使用两个临时后端及本地临时 Git 仓库；不需要接触真实仓库或会话：

```powershell
$env:DSH_INSTALL_ROOT = '安装的 DSH 包绝对路径'
node test/framework-smoke.manual.mjs
```

覆盖数据往返、配置路径、本机隐藏绑定、外机导入、重复下载、双端对话冲突分裂/重绑定及原生源不被桥接改写。未设置安装路径时只跑独立数据层。没有为 UI/普通同步新增防御测试。
